# Fix: Empty Response ValueError in Agent Nodes

## Problem

The `google-genai` SDK's `response.text` property raises `ValueError` when the response has no text content (safety blocks, function-call-only responses, or empty candidates). Two agent nodes access `.text` without adequate protection:

1. **`answer_generator.py:53`** — `answer = resp.text or ""` has zero error handling. A ValueError here crashes the entire agent pipeline with a generic 500.
2. **`reflexion_evaluator.py:152`** — `raw_text = resp.text or ""` is inside a try/except, so it doesn't crash, but it silently falls back to `completeness_score=0.5`, causing the stuck-loop detector to force-accept after 2 iterations with a poor answer.

## Root Cause

`or ""` is a falsy-value fallback, not an exception handler. When `.text` raises, the assignment never executes, and the variable stays at its prior value (`""`). The existing defensive pattern at `rag.py:371-380` shows the correct approach: try `.text` first, then walk `candidate.content.parts` with `hasattr` guards.

## Plan

### Step 1: Add a shared helper to `rag.py`

Insert a `safe_extract_text(response)` function near `generate_with_failover` (around line 476). It implements the same logic as `llm_generate` lines 362-380 but without the cache/raise wrapping:

```python
def safe_extract_text(response) -> str:
    try:
        if response.text:
            return response.text
    except (ValueError, AttributeError):
        pass
    if response.candidates:
        candidate = response.candidates[0]
        if candidate.content and candidate.content.parts:
            parts = [p.text for p in candidate.content.parts if hasattr(p, "text") and p.text]
            if parts:
                return "".join(parts)
    return ""
```

### Step 2: Update `agent/nodes/answer_generator.py`

Replace line 53:
```python
answer = resp.text or ""
```
with:
```python
answer = rag.safe_extract_text(resp)
```

### Step 3: Update `agent/nodes/reflexion_evaluator.py`

Replace line 152:
```python
raw_text = resp.text or ""
```
with:
```python
raw_text = rag.safe_extract_text(resp)
```
